# TrustLens AI — Cloud Nexus 2026

## Overview

TrustLens AI is an IoT security project that simulates device telemetry, transports messages through MQTT, and supports the analysis of potentially suspicious device activity.

## Project Structure

- `simulator/` — Generates simulated IoT telemetry.
- `messaging/` — Receives telemetry through MQTT.
- `detection/` — Contains detection rules, risk scoring, model training, evaluation, and pipeline code.
- `data/` — Stores telemetry datasets.
- `dashboard/` — Contains dashboard-related files.
- `docs/` — Project documentation.
- `forest_model.py` — Machine-learning model-related code.
- `requirements.txt` — Python dependencies.

## Prerequisites

- Python installed
- An MQTT broker accessible at `127.0.0.1:1883`
- Python packages listed in `requirements.txt`

Install dependencies:

```bash
pip install -r requirements.txt
```

## Running the MQTT Demo

Start your MQTT broker first.

Open two separate terminals in the repository root.

**Terminal 1 — Start the simulator**

```bash
python simulator/simulator.py
```

**Terminal 2 — Start the subscriber**

```bash
python messaging/messaging/mqtt_subscriber.py
```

The simulator publishes telemetry to the `trustlens/telemetry` topic. The subscriber listens to that topic and prints received messages.

The simulator periodically generates intentionally unusual telemetry for `device_003` to demonstrate suspicious-looking activity.

## Detection Components

The `detection/` directory contains the model, rules, risk engine, evaluation, and pipeline components. Their exact execution workflow and integration with MQTT should be verified before claiming that live messages are automatically classified.

## Development Notes

Telemetry generated by the simulator is synthetic and is intended for development and demonstration. Suspicious-looking values do not establish that a real attack has occurred.
